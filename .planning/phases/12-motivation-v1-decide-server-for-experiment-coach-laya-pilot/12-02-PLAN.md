<objective>
Give the release-gating verifier a declared pilot waiver (D-19) that can only ever excuse an ECE failure (never margin,
D-20), only for the exact run it was declared for, and is visible in every verdict line — and prove each refusal with a
falsification test. This plan builds the decision and its contract policy; plan 12-03 adds the artifact identity field and
the trainer's write; plan 12-11 adds the motivation-v1 declaration before the one gate run.

Purpose: "pack still refuses any undeclared failure" (D-19) is a permanent capability of a release-gating tool (rated
costly in CONTEXT), so the refusal side is built and tested before anything can use the acceptance side.

Output: the contract block and schema rows, the Rust decision, the CLI line field, the tests, the Python optional-key rule.
</objective>
