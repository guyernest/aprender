| config -> row provenance | backend/hardware identity must come from execution, not config echo |
| driver shell -> verdicts | rc discipline; pinned binary |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-05-09-01 | Spoofing | backend identity | mitigate | ExecutionBackend::identity / pipeline gpu accessors only; cpu fallback cannot fabricate GPU |
| T-05-09-02 | Tampering | transported rows | mitigate | --record verifies digest, schema, expected cell, and filename-key agreement before recording |
| T-05-09-03 | Tampering (uncontracted cell) | seed/shots inputs | mitigate | bench layer refuses non-contracted seed/shots with a contract-naming error (42 explicitly excluded) |

| T-05-09-05 | DoS | oversized row/manifest reads | mitigate | bounded read before parse (16 MiB house cap pattern from 04-18) in the adapter's file readers |
