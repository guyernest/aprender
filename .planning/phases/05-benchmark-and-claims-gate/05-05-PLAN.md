| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-05-05-01 | Tampering | row files | mitigate | semantic_hash over canonical bytes verified in from_bytes before return (SelectionManifest pattern) |
| T-05-05-02 | Repudiation (selective omission) | expectation set | mitigate | 80 cells enumerated in the contract and derived in code; include_str! parity test pins the two together |
| T-05-05-03 | Tampering (RNG smuggling) | row schema | mitigate | deny_unknown_fields everywhere; contract textually excludes bootstrap fields (D-06) |
