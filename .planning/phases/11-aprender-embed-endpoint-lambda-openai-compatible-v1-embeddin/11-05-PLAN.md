endpoint a thin transport that re-implements nothing (OPS-03).

Facts measured while planning (2026-10-23, HEAD 6cc955d21):
- `SetFitBert` has private fields `tokenizer: MiniLmTokenizer`, `encoder: BertSentenceEncoder`, `freeze`; a child module of `setfit` can read them. `tokenize_batch(&self, &[&str]) -> Result<SentenceBatch, SetFitError>` is `pub(crate)` (mod.rs:616); `encode_batch_traced` is `pub(crate)`; `encode_texts` is `tokenize + encoder.encode`. `BertSentenceEncoder::encode(&batch)` is the call `encode_texts` makes (mod.rs:582-585).
- `TruncationFact { truncated: bool, original_len: usize }` (original_len counts special tokens) and `SentenceBatch::{truncation, attention_mask, batch, seq}` are public; classify.rs:739-780 has the private `truncation_fact` and `consumed_positions` helpers this door mirrors (get-based, typed error, never a fabricated false).
- `SetFitError` variants include `BatchInvalid { reason }` (used for an empty list) and `Op(OpError)`; `Tensor::data() -> &[f32]` and `shape() -> &[usize]` are public.
- `aprender::autograd::{no_grad, is_grad_enabled, graph_tape_len, clear_graph}` are public; the tape and the flag are thread-local; `no_grad` restores the previous flag after the closure returns but has no drop guard, so a panic inside leaves the flag off for that thread.
- The slice fixture (`SetFitMiniLm::from_slice_fixture`, feature conformance-fixtures) has 2 layers, hidden 64, 64 positions and a 97-id vocabulary closure, so it can encode only the in-closure texts of existing fixture cases and never a 256-token text; the pinned tokenizer.json (tests/fixtures/setfit/tokenizer.json, 455 KB) is the real one, so tokenization and fact extraction can be tested on long text without weights.
- CI runs `cargo test -p aprender-core --features setfit --lib setfit` (fragment 010) and the harness `--features setfit,conformance-fixtures --test setfit_conformance` (fragment 020); real-weight tests are `#[ignore]` and gated by the `model-tests` feature (full_weight_parity.rs) and read the pinned checkout from APRENDER_MINILM_DIR (default ~/.cache/aprender/minilm-l6-v2-1110a243).
- Mutation gate: CI runs cargo-mutants on the PR diff with MUTANTS_MAX_MISSED defaulting to 0; a `clear_graph` call after a no_grad closure would be an equivalent mutant (the tape is already empty), which is one more reason this door does not call it.
