  <action>
Write `scripts/embed_endpoint/mock_runtime.py`, standard library only, with no sibling import. Tests first: write the `--selftest` case table and its stand-in client, run it red, then write the server.
1. `MockRuntime`: an HTTP server on an ephemeral 127.0.0.1 port (ThreadingHTTPServer) serving GET /2018-06-01/runtime/invocation/next (the next queued payload as the body, headers Lambda-Runtime-Aws-Request-Id with a fresh id, Lambda-Runtime-Deadline-Ms of now plus the configured deadline in epoch milliseconds, Lambda-Runtime-Invoked-Function-Arn with a fixed fake name that is not an ARN of any account; when the queue is empty the request is held open until the server stops), POST .../invocation/<id>/response and .../invocation/<id>/error (recording kind, request id, the body bytes and the Lambda-Runtime-Function-Error-Type header; the answer is 202), and POST .../runtime/init/error (recorded as an init failure). Responses carry Content-Length. A payload is a `bytes` object sent VERBATIM, or any other Python value serialized with json.dumps (compact separators, ensure_ascii False, UTF-8): a `str` event is therefore a JSON string literal, never raw text.
2. `invoke_many(binary, events, env, deadline_ms=60000, timeout_s=300)`: the finite batch. It starts the server, spawns the binary with AWS_LAMBDA_RUNTIME_API set to host:port, AWS_LAMBDA_FUNCTION_NAME, AWS_LAMBDA_FUNCTION_VERSION and AWS_LAMBDA_FUNCTION_MEMORY_SIZE set to fixed values and the caller's `env` (the caller's own environment is NOT inherited except PATH and HOME), waits until it has one record per event, a recorded init error, the child's exit or the timeout, kills the child, and returns a list of `{kind: "response"|"error"|"init_error"|"no_answer", body, error_type, request_id}`; `body` is the parsed JSON when the bytes parse and otherwise {"raw_utf8": text} or {"raw_b64": base64} when they do not decode. A child that exits before answering yields `no_answer` entries immediately (never a hang until the timeout).
3. `Session(binary, env, deadline_ms=60000, timeout_s=300)`: a context manager over the same server that starts the child ONCE; `invoke(event, timeout_s=None)` queues one payload, waits for exactly one record (or the child's exit, or the timeout) and returns it in the same shape; `pid` is the child's process id; `alive()` reports whether it still runs; `close()` (also on `__exit__`) kills the child and stops the server. An invoke after the child died returns a `no_answer` record at once. This is the transport the plan 11-11 harness keeps open across all its checks.
4. CLI: `mock_runtime.py --bin <path> --event <file> [--event <file> ...] [--raw-event <file> ...] [--env K=V ...] [--out <dir>]` prints one JSON line per event (a --event file is parsed as JSON and re-serialized, a --raw-event file is sent as its exact bytes) and exits 0 only if every record is a `response`; `--selftest` runs the case table below.
5. `--selftest` writes a small stand-in runtime client in Python to a temporary directory (it performs GET next and POST response or error like the real runtime; its behaviour is chosen by an environment variable and it reports the sha256 and length of the payload it received and its own pid in the response body) and requires every one of these cases to pass: (1) one event echoed; (2) two events served in order; (3) an error post recorded as kind error with its type; (4) an init-error post recorded; (5) a client that exits without answering gives no_answer at once, well before the timeout; (6) a client that never answers is killed at the timeout; (7) a bytes payload that is invalid UTF-8 arrives with the identical sha256; (8) a 100,000-deep nested array and a payload `{"a":1e999}` arrive verbatim; (9) a 6 MiB body arrives verbatim; (10) the deadline header is an epoch-millisecond value in the future; (11) a persistent Session answers three invokes from ONE process (the same pid in all three); (12) after the child is killed externally the next Session.invoke returns no_answer at once; (13) Session.close kills the child (the pid is gone); (14) the caller's environment is not inherited (a variable set in the parent is absent in the child, PATH and HOME are present). It prints `MOCK RUNTIME SELFTEST OK <n> cases`.
