## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filesystem → CLI → crate | Manifest and JSONL bytes from disk are untrusted until the crate's boundary validates them |
| CLI output → later phases | The written selection manifest is the artifact Phase 5 hands to both methods |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-29 | Tampering | edited selection manifest replayed into pairs | mitigate | run_pairs validates manifest membership against the ingested train split; crate endpoint gate rejects foreign IDs (behavior test) |
| T-02-30 | Elevation (data) | selection over a compat-profile dir | mitigate | Ingest maps the setfit profile to CompatibilityTest declarations (02-06); no Split<Validation> witness exists → the crate call fails typed; surfaced as structured CliError |
| T-02-31 | Tampering | partial writes corrupting a manifest | mitigate | create_new no-clobber + rollback-on-partial-write discipline copied from data_tweeteval |
| T-02-32 | Repudiation | ambiguous human-only output | mitigate | --json machine-readable output with semantic_hash and replay tuple in both commands |
</threat_model>
