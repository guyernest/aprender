result per text, probabilities that sum to one and index the labels in task order, and the served sha
equal to the pin. Build it as a `--replay` mode of the existing probe example (one implementation of the
request path), prove it on the loopback fixture, then against the live stance server.

gated; the Phase 8 probe checks identity and labels but never asserts per-result shape or sums. Having
the mode ready before the redeploy means plan 10-08's replay is a run, not a build.

Output: `run_replay` + `ReplayReport` in src/probe.rs with tests; `--replay N` in examples/probe.rs; a
live JSON line against the stance server kept in the SUMMARY.
