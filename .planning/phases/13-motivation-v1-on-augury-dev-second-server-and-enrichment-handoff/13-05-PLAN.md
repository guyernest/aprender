<objective>
Write the selection guidance the partner needs to pick which stored posts go to the expert (D-17), as a note with fixed
numbers and a seeded rule, and a small reference implementation of exactly that rule over motivation-record-v1 files, so the
prose cannot be read two ways.

Purpose: the next retrain learns most from the model's errors and needs an unbiased control to be compared honestly;
selecting only confident rows would waste the expert's budget.

Output: scripts/laya_train/select_motivation.py and 13-SELECTION-NOTE.md.
