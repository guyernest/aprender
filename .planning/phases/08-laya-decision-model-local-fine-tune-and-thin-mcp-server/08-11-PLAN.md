the Phase 7 lesson is that an accepted region must be measured, not assumed. Gemini puts the

cold sample of both shapes is judged, not a single one.

bindings to `implemented` and tightens the audit — moves AFTER it to Wave 10, so the live equation
`accepted_region_cold` is never declared implemented before this plan's evidence exists or after a
`hold`. Codex's alternative (make 08-12 a dependency of this plan) is rejected: it would flip the
live binding before the live run. Its underlying concern — do not deploy before the audit/binding
gates are green — is met by this plan's precondition (pending-tolerant `contract-audit-phase8`, the
strict-binding guard, the Phase 8 lib tests and the deploy selftest must pass on the deploy commit).

Output: the live server; `08-DEPLOY-EVIDENCE.json` (no account id); the Lambda crate README updated;
the outcome recorded for 08-12.
