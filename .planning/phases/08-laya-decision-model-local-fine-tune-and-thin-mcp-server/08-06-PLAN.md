<objective>
Ship the thin stdio MCP server `aprender-mcp-decide` (D-15) exposing ONE task-bound `classify` tool
(D-09) over a verified decide .apr: list of texts in with a contract-owned maximum (D-10), label +
ordered calibrated probabilities + truncation flag out (D-11, D-12), model identity in every response.

copies the `aprender-mcp-setfit` template — transport-only, in-process, bounds owned by the transport
and named from a contract — so the Lambda crate (08-07) is a thin shim over it.

Output: the crate (lib + stdio bin + e2e test), its README, workspace member, README count, the
FALSIFY-MONO-011 register entry.
