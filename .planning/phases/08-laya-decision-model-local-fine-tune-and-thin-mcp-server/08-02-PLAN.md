   global `*.safetensors` rule, so the CI packer path reads the same file format as production. They
   are synthetic random-init weights (no licensed or personal data); the "weights are never committed"
   rule is about real checkpoints, which stay under root-anchored `/models/`.

   `crates/aprender-decide/tests/fixtures/`. It contains TweetEval tweet text, and D-14 intends
   `aprender-decide` to be published — copying it would ship tweet text to crates.io. The gated
   full-model test (plan 08-09) reads it from its existing tracked path
