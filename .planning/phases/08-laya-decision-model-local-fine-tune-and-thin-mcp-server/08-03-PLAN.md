<objective>
Land ModernBERT in aprender-core as a reusable encoder (D-13) by lifting the spike-025 encoder
numerics byte-for-byte onto the house GEMM and loader, and prove it against a transformers oracle in
CI through the tiny fixture from plan 08-02.

Purpose: the spike proved the math (probs 3.8e-6, ids 14/14) outside the workspace. Productising it
means: lint-clean code with typed errors, a loader that reads .apr through the one F16 widening path,
a tensor-name prefix so a plain HF ModernBERT and Laya's `encoder.`-prefixed copy both load, and
parity tests that run in `workspace-test`.

Output: `crates/aprender-core/src/models/modernbert/{mod,config,gemm,embeddings,layer,encoder,load}.rs`,
registration in `models/mod.rs`, in-module tests.
</objective>

- `gemm.rs`: `Linear { w, b, out, inp }` (weight `[out, in]` row-major is the GEMM A operand, no

  `Result<Vec<f32>, ModernBertError>` instead of panicking on a `gemm_blis` error (typed error, no

  `gelu_exact(x)` as `0.5 * x * erfc_precise(-x / SQRT_2)` in f64 through
  `batuta_common::math::erfc_precise` (replaces the spike's `libm::erf`; parity is re-proved by the
  tests below — RESEARCH A11); `rope_rotate_half(x, l, heads, hd, theta)` with the torch f32
  inv_freq/angle order; `attention(q, k, v, l, heads, hd, window: Option<usize>)` bidirectional with
  the inclusive window; `ModernBertLayer` (layer 0 has no attn_norm; fused `Wqkv` split into q/k/v;
  GeGLU MLP `Wi -> chunk(input, gate) -> gelu_exact(input) * gate -> Wo`). Make `Linear`,
  `layer_norm`, `gelu_exact`, `attention` public and re-exported: aprender-decide's Laya head and
  scorer reuse them (one implementation, OPS-03) rather than copying them.

  errors naming the field. `window()` = `local_attention / 2`.
