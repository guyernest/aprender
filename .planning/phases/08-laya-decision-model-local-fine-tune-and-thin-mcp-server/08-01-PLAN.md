judged by — BEFORE any run is read (D-07's claims-gate philosophy, Phase 5 precedent). Wire them
into `make contract-validate` and a blocking `contract-audit-phase8` so they are checked from the

same YAMLs are the single schema source for the Python trainer, the Rust artifact and the server.

`contracts/laya-parity-v1.yaml`, `contracts/decide-apr-v1.yaml`; Makefile wiring; pending binding
rows; README contract count.

criteria reorder, which contradicts D-05's order-as-index rule); Q4 — the D-19 demo cell is
