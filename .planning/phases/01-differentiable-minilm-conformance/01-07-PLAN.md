Review-driven revisions in this pass (2026-08-08, `/gsd:plan-phase 1 --reviews`):
- **D-08's claim is restated honestly.** `SetFitMiniLm` is NOT the sole construction path, because
  `MiniLmTokenizer::from_bytes`, `MiniLmImport::open`, and `BertSentenceEncoder::from_import` must
  stay public for the pinned-import and conformance-fixture paths. Sealing them was considered and
  rejected: it would break the fixture gates. The enforceable property — implemented in 01-06 and
  asserted here — is that a mismatched pair cannot be USED: every forward call compares
  `batch.tokenizer_sha256` against the encoder's, and rejects a mismatch with a typed error. The
  truth statement now says what is actually delivered.
- **`apply_freeze` semantics are specified**: REPLACEMENT (each call fully defines the policy),
  idempotent, order-insensitive, duplicate-tolerant, and reversible via `clear_freeze()`.
- **A dedicated `pair_cosine_mse` contract equation** (declared by 01-01 Task 1) is annotated,
  rather than mislabelling this wrapper as raw `mse_loss` — its inputs are two [B,H] embedding
  matrices plus binary labels, not a prediction vector and a target vector.
- **Label validation rejects non-finite values BEFORE the binary comparison** — `NaN != 0.0 && NaN != 1.0`
  happens to reject NaN today, but only incidentally; make it explicit and tested.
- **ENC-04 wording aligned** with the corrected gate semantics (aggregate per component + data-driven
  exemptions).

pub struct SetFitMiniLm { /* owns MiniLmTokenizer + BertSentenceEncoder — private fields */ }
impl SetFitMiniLm {
    pub fn from_pretrained_dir(dir: &Path, root_seed: u64) -> Result<Self, SetFitError>;

    pub fn from_slice_fixture(fixture_dir: &Path, root_seed: u64) -> Result<Self, SetFitError>;

    pub fn set_training(&mut self, training: bool);

    /// REPLACEMENT semantics: the argument fully defines the freeze policy. Any group not listed
    /// becomes trainable again. Idempotent, order-insensitive, duplicate-tolerant.
    /// `apply_freeze(&[])` is equivalent to `clear_freeze()`.
    pub fn apply_freeze(&mut self, groups: &[FreezeGroup]) -> Result<(), SetFitError>;
    /// Restore the D-20 default: every parameter trainable, requires_grad(true) everywhere.
    pub fn clear_freeze(&mut self);

    /// Partition respecting freeze config. Default (no apply_freeze): ALL trainable (D-20).
    pub fn trainable_parameters_mut(&mut self) -> Vec<(String, &mut Tensor)>;
    pub fn frozen_parameters(&self) -> Vec<(String, &Tensor)>;
}

#[derive(Debug, Clone, PartialEq, Eq, PartialOrd, Ord)]
pub enum FreezeGroup {            // validated structure, NOT a glob DSL (D-22)
    Embeddings,
    LayerAttention(usize),        // encoder.layer.N.attention.* (self + output.dense)
    LayerFfn(usize),              // encoder.layer.N.intermediate.* + encoder.layer.N.output.dense.*
    LayerNorm(usize),             // both LayerNorms of layer N
}
