<interfaces>
Fixture JSON schema (the contract plans 01-05 and 01-08 parse against — keep field names exact):

- `tokenizer_cases.json`: `{ "revision": "1110a243...", "tokenizer_sha256": "...", "cases": [ { "id": "case-name", "texts": [".."], "max_length": 256, "input_ids": [[..u32]], "token_type_ids": [[..]], "attention_mask": [[..0/1]], "truncated": [bool], "original_token_counts": [int] } ] }`
  Cases must cover: single short text, mixed-length pair batch, a >256-token truncation case, CJK text, accented text, mixed-case text.
- `slice_config.json`: `{ "num_layers": 2, "hidden": 64, "heads": 4, "intermediate": 256, "vocab": <N~256>, "positions": 64, "layer_norm_eps": 1e-12, "source_revision": "1110a243..." }`
- `vocab_remap.json`: `{ "orig_to_slice": { "<orig_id>": <slice_id>, ... } }` (closure of all token ids used by fixture texts + specials)
- `forward_per_layer.json`: per case: `{ "input_ids_slice": [[..]], "attention_mask": [[..]], "embeddings_out": [...], "layer_outputs": [ [...], [...] ], "final_tokens": [...] }` (row-major flattened arrays with shape fields)
- `pooling_normalize.json`: pooled + normalized [B,64] per case
- `loss_pair.json`: `{ "pairs": {a_ids, b_ids, masks, labels}, "cosine": [..], "mse": <scalar> }`
- `gradients.json`: `{ "<hf_dotted_name>": {"shape": [..], "grad": [..]} }` for ALL slice parameters, pooler.* excluded
- `optimizer_step.json`: `{ "adamw": {"lr": 2e-5, "betas": [0.9, 0.999], "eps": 1e-8, "weight_decay": 0.01}, "post_step": { "<hf_dotted_name>": [..] } }`
- `batch_invariance.json`: same sentence encoded at batch 1 and inside a padded batch-3
- `full_model_reference.json`: 3 sentences -> final [3,384] normalized embeddings from the FULL pinned model (feeds the D-10 gated suite)
- `tolerances_measured.json`: `{ "<fixture_family>": {"max_abs_f32_f64_delta": x, "recommended_tolerance": y} }`
</interfaces>
