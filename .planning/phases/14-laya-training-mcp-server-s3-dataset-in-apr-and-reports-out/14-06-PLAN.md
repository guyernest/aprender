<objective>
Build the x86_64 CUDA training container's contract: `run_step.py` (the only program SageMaker runs), the image
definition, and the deterministic base-snapshot staging with its offline-load proof.

Purpose: the container is the one place x86 and CUDA touch the run. It must run the pinned trainer unchanged, refuse to
burn the 6 h ceiling on a CPU fallback, survive a stop with its reports, and load the sha-pinned base from S3 offline.
Output: run_step.py (train / probe / probe-sigterm), context-paths.txt, Dockerfile.train, stage_base.py,
base-stage.json.
