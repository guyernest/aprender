## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| job-written S3 objects -> finalizer | files written by the training container and the pack task decide the record |
| EventBridge -> finalizer | events may repeat or come from another machine |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-14-15 | Tampering | finalizer reading outcome/pack files | medium | mitigate | only the server's roles can write runs/* (14-08 IAM); a completed verdict additionally requires pack_laya verify's accept line, which re-derives the gate from hash-bound probabilities; byte caps on every read |
| T-14-16 | Repudiation / Tampering | duplicate or late invocations | medium | mitigate | first writer wins in DynamoDB and in verdict.json; the record is written before any S3 object (fin_duplicate, fin_first_writer_wins, fin_cancel_race) |
| T-14-57 | Repudiation | a client-cancelled task | medium | mitigate | the finalizer attaches the cancelled payload with attach_result_if_absent (result only when none is stored, status unchanged), so the cancel leaves a durable, readable record and never a keep tag (fin_cancel_first, fin_cancel_late) |
| T-14-17 | Denial of service (financial) | aborted / timed-out executions | high | mitigate | StopTrainingJob fallback when the job is still InProgress (fin_abort_event, fin_timeout_event) |
| T-14-18 | Tampering (retention) | tags | medium | mitigate | default expire on every write, keep only for completed, read-back, error-and-retry on tag failure (fin_tag_failure) |
| T-14-19 | Spoofing | foreign EventBridge events | low | mitigate | the state machine ARN must equal the configured one (fin_foreign_machine) |
</threat_model>
