<objective>
Make the request-side dataset check (D-08) provably the trainer's own rule set: factor train.py's step-1 data checks
into one Python function the trainer calls, write ONE committed case table, and replay it through that function and
through the Rust pre-filter, so the two cannot drift silently.

Purpose: `validate_dataset` and the first step of `train` answer in seconds before a GPU job is paid for. A pre-filter
that refused what the trainer accepts would block valid work; one that accepted what the trainer refuses would waste a
paid start. The table makes either visible.

Output: data_cases.json (+ its generator), validate_data_dir, the completed validate.rs, the mutation evidence.
</objective>
