aws-cli: `aws lambda invoke --function-name <fn> --cli-binary-format raw-in-base64-out --payload file://<event.json> --log-type Tail --query LogResult --output text <out.json>` → the LogResult is base64 of the last 4 KB of the log; `REPORT` line fields: `Duration: <ms> ms`, `Billed Duration: <ms> ms`, `Max Memory Used: <MB> MB`, `Init Duration: <ms> ms` (cold only). Price: `mem_mb/1024 * billed_ms/1000 * 0.0000133334`.
Shapes (shapes.py): `shape_short(model, max_tokens)`, `shape_tools2`, `shape_tools10`, `shape_turn2(turn1_body, tool, max_tokens)` — every user prompt carries a nonce `[ref <ns>]`.
cpu_part: `[entry] host: nproc=… cpu_part=0xd40 …` — present in the cold invocation's tail; otherwise `aws logs filter-log-events --log-group-name /aws/lambda/<fn> --filter-pattern '"[entry] host:"' --limit 1 --query 'events[-1].message'`.
Inputs from plan 09-06: `.ids/function.json` (function, image_digest, apr_tag, gguf_sha256, memory_mb), `.ids/aws.json` (profile, region, log_group); the 09-01 probe-record contract (label set, naming rule, interim fixed name and pin string `upstream-main+PRs`) and `probe_openai.py` flags (`--base --model --profile --label --pin --server-version --out`).
Spike-031 prices used ONLY as conservative guard estimates (context, never the measurement): two-tool turn ≈ $0.0095, ten-tool prefill ≈ 146 s billed ≈ $0.0199, cold start that is answered 401 ≈ $0.005.
